# Security Policy

## Supported Versions

The following table shows which versions are currently supported versions and for which you can report a security vulnerability. If you find a vulnerability in an unsupported version, please upgrade.

| Version | Supported          |
| ------- | ------------------ |
| 1.22.5  | :white_check_mark: |
| 1.22.4  | :white_check_mark: |
| 1.22.3  | :white_check_mark: |
| 1.22.2  | :white_check_mark: |

## Reporting a Vulnerability

Report the vulnerability in Issues section on github.com/paulsheer/ming64x

Please wait 48 hours for a response.

If your vulnerability is accepted. An author will respond the the Issue inline.
